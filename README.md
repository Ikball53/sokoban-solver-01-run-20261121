# Sokoban Solver

A push-optimal Sokoban solver that splits each level into its hallway and rooms, solves every room independently with a push-level breadth-first search, and concatenates the room solutions with hallway walks. The repository ships a minimal loader; the solver itself is supplied as an entry secret.
